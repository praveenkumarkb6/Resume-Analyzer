# Resume Analyzer

A web-based Resume Analyzer that analyzes a resume against a given job description and identifies matching skills.

## Live Website

https://resume-analyzer-frontend-c27z.onrender.com

## Backend API

https://resume-analyzer-tz24.onrender.com

## GitHub Repository

https://github.com/praveenkumarkb6/Resume-Analyzer

## Technologies Used

- React
- Vite
- Python
- Flask
- PDF processing
- REST API
- Render
- GitHub

## Main Features

- Upload resume PDF
- Enter job description
- Extract resume content
- Analyze required skills
- Compare resume skills with job skills
- Display analysis results
